# 验证与已知限制

## 已完成的离线检查

- pycollada 独立读取模型，检查场景引用、三角面、法线、UV、坐标与出生高度。
- DDS 头、mipmap、图像解码及基础颜色 sRGB 声明检查。
- 路肩间隙、柏油全宽 UV、轮胎印透明混合及曝光脚本退出恢复。
- ZIP CRC、目录结构、压缩格式、磁盘文件一致性及安装哈希核对。
- 使用本地游戏 Lua 解析计时赛，检查闭环顺序、18 道计时门和原赛车线穿越顺序。
- 原生任务初始化、1–20 圈设置、评分阈值及多圈最佳单圈结算。
- 原生导航导入代码读取 306 个节点；主赛道闭环和维修区连接检查。
- 原生数学库检查起步旋转。最终 180° 修订依据用户游戏内反馈，不能以离线检查代替实际车辆朝向验证。

工具不会启动 BeamNG。测试中的部分场景/车辆接口使用替身，不能验证完整引擎渲染、UI 或轮胎物理行为。

## 建议游戏内复测

1. 自由驾驶载入，确认小地图显示赛道闭环及维修区道路。
2. 在正午和弱光下检查路肩、路面和轮胎印；移动视角检查围栏闪烁。
3. 维修区接取任务，分别测试静止和飞驰起步；确认车头朝赛道正向。
4. 测试 1 圈、2 圈，确认检查点顺序、跨线计时、圈数与完赛成绩界面。
5. 确认最佳单圈 ≤80/70/65 秒分别获得 1/2/3 星，时间超出 80 秒不授予时间星。

## 右前轮漏气调查

用户报告全力驾驶一两圈后可能出现右前轮漏气。对原赛车线及左右偏移 0.85 米的轮迹检查，共 3930 个采样点均能在上下 1 米内找到碰撞支撑；采样到的近地突出接触属于路肩，最高约高于柏油 7.3 厘米。19326 条匹配路面边的最大端点高度差约 7.6 毫米。

暂未找到能明确归因于赛道的右前轮漏气故障。采样不涵盖所有车辆尺寸、行车路线、压路肩方式和轮胎物理过程，也不能证明赛道绝无碰撞问题。没有修改车辆损伤或轮胎参数来掩盖现象。建议以同一车辆默认设置/当前设置，以及避开路肩/正常驾驶做对照。

## 其他限制

- 结构网格主要使用可见模型碰撞，尚未为整张地图制作独立优化碰撞网格。
- 路面摩擦按材质类型映射，未数值复刻 AC `surfaces.ini`。
- CSP 着色、夜间灯光和天气不是完整移植。
- 植被使用 LOD；整体性能仍取决于硬件、画质和车辆数量。
- 细铁丝网投影已关闭以减轻阴影闪烁；实体护栏保留投影。
- 导航路网用于地图道路显示；未启用或验证环境交通。
