# Tianma BeamNG V1.0

上海天马赛车场 BeamNG.drive 转换版。原始 Assetto Corsa 地图作者 SkytenZ，转换与整理 MOKALIKS。

## 内容

- 赛道与维修区、三个出生点、带 LOD 的立体植被。
- 深灰柏油、半透明轮胎印、红白路肩与曝光调整。
- 主赛道与维修区地图道路显示。
- 维修区中段接取计时赛，静止/飞驰起步、1–20 圈（默认 3 圈），17 个中途检查点。
- 最佳单圈 ≤1:20 一星、≤1:10 两星、≤1:05 三星。
- 修复完赛评分参数缺失、调整围栏闪烁；最终起步朝向按实测反馈旋转 180°。

## 安装

退出游戏，把附件 `st_stctk_ac_port.zip` 放入 BeamNG 用户目录的 `mods` 或 `mods/repo`，不要解压。进入自由驾驶选择 **Shanghai Tianma Circuit v1.0**。升级前移除其他目录的同地图旧副本。

不要把 GitHub 自动生成的 **Source code (zip)** 当作模组安装。

## 验证与限制

已通过离线模型、材质、压缩包、原生 Lua 任务/导航及星级边界检查。地图此前已由用户载入和驾驶，最终起步方向调整与全部视觉效果仍需手动复测。

暂未找到能明确归因于赛道的右前轮漏气故障；采样检查不等于完整轮胎物理测试。详见仓库 `docs/TESTING.md`。资源归属见 `THIRD_PARTY_NOTICES.md`。
